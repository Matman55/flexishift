# FlexiShift

Matching-app voor Belgische flexijobs: shiftwerkers zetten hun vrije uren klaar, werkgevers vinden wie écht kan.

Dit is een **React + Vite**-website, geen Streamlit-app. Online bekijken gaat via **GitHub Pages**, niet via Streamlit Cloud.

## Demo

- Werkzoekende: Emma Peeters
- Werkgever: Café De Kroon

## Lokaal

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Online

Na een push naar `main` bouwt GitHub Actions de site en zet hem op GitHub Pages.
